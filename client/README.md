# Client package

This directory contains the Next.js web client for the Project Management Dashboard. For repository setup, environment variables, local development, build commands, and architecture, see the [root README](../README.md) and [development guide](../docs/development.md).

Install dependencies with `npm ci`, configure `client/.env.local` using [`client/.env.example`](.env.example), and run `npm run dev` from this directory.
